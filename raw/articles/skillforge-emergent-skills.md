# SkillForge 涌现式 SKILL 与图谱化记忆

> 基于 docs/emergent-skill-通俗版.md 和 ADR-0008 整理

---

## 一、核心理念：一切是一张网络

**记忆和技能不是两套东西，是同一张网里不同的点。**

```
你 = 一个节点
你的部门 = 一个节点
"查购物车" = 一个技能节点
"销售部门开通了购物车功能" = 它们之间的一条线
```

## 二、涌现式 SKILL

### 2.1 什么是"涌现"

**涌现的意思是：它自己长出来，不是被事先安排好的。**

| 传统做法 | 涌现式 |
|---------|--------|
| 人开会商量"做哪些技能" | 系统观察"哪些操作被反复用" |
| 一个一个做出来登记在册 | 让"常用的操作串"自己聚成一团 |
| 规定好谁能用 | 谁够得着谁用 |

**例子**：
- 发现"查库存+查价格+下单"总一起用 → 自然聚成"购物"技能
- 今天老这样用，技能就这样长；习惯变了，技能跟着重新长

### 2.2 类比

- **传统**：图书馆的书手工分类上架、查卡片目录
- **涌现**：书是看的人借出来的，被高频一起借的自动靠在一起 → **书架适应人**

## 三、记忆网络

传统记忆像**清单**：`"123: 用户喜欢咖啡"`

记忆网络像**关系网**：不只记"喜欢咖啡"，还记"咖啡→用户习惯→常去品牌→品牌促销"……

问"推荐一个符合用户口味的东西"，它不是翻一条最像的记录，而是**顺着网走到真正相关的地方**。

## 四、规模性判据（ADR-0008 核心）

### 4.1 传统 ACL：平方劣化

```
维护成本 = O(用户 × 技能)

每加一个用户，要为他对每个技能配一条
每加一个技能，要为每个用户配一条
```

**人越多 × 功能越多 → 记录爆炸式增长**

这不是哪个团队不够细心 — 是"人 × 技能"这种两两配对的表格，在规模大了之后物理上就撑不住。

### 4.2 涌现图：亚线性摊薄

```
加一个人 = 加一条 membership 边(O(1)) → 继承组织全部能力
加一个技能 = 连到想共享的 org(O(1)) → 铺给所有人
```

**连接越多、共享越广、摊薄越大 → 规模越大越划算**

### 4.3 一句话判据

```
ACL   = pairwise 组合爆炸    → 规模上：越用越难、物理性碰壁
Graph = 结构化共享摊薄       → 规模上：越用越好、连越密越省
```

## 五、控制目标（Control Target）

### 5.1 ACL 没有明确的控制目标

ACL 授权行的本质是 `(subject, object)` — "谁能对哪个资源做什么"。

但涌现式 skill 是一团使用数据的子图，边界会随真实使用 merge/split 演变：
- 授权时"Alice 可用 skill_cart"
- 演变后 skill_cart 与其他技能合并成新子图
- 那个对象在现实中已不存在
- ACL 行钉在了一个消失的对象上

### 5.2 图谱的解法

把控制目标从"一个资源单元"换成**"从主体出发沿 membership/hierarchy 可达的子图（拓扑关系）"**：
- 拓扑不要求 skill 有固定边界
- 今天可达、明天演变后重遍历仍可达
- 永不钉死

## 六、全量加载问题

### 6.1 现状

当前 Hermes 全量加载所有 SKILL 简介注入每轮 prompt：

```
O(N) × 每轮 token 开销  ← N = skill 数量
```

### 6.2 ACL 过滤不是解

- ACL 过滤是**前置白名单**
- 话语权越大的人，拥有的技能越多，过滤后剩的反而越多
- ACL 是"删减视图"，不是"按需产出"

### 6.3 正确的解

**按需检索**：根据当前任务，只加载最相关的 Top-N 技能简介。

## 七、图谱化 SKILL

### 7.1 SKILL 作为一等图节点

SKILL 不再是一个独立的文件系统目录，而是图谱中的一个节点：
- 与人、组织、知识、事实共享同一张网
- 通过边关系表达"谁能用"、"依赖什么"、"产生什么"

### 7.2 型态分置

| 层 | 存储 | 特性 |
|---|------|------|
| **实例态** | tasks/task_items 表 | 快变量：高频写、生命周期短 |
| **型（模板/规律/前置条件）** | 知识图谱 | 慢变量：低频更新、长期积累 |

task 节点持有对 KG 节点的引用，共享上下文。高 churn 的实例态不灌进写时重的图。

---

## 八、总结

| 维度 | 传统方案 | 涌现式方案 |
|------|---------|-----------|
| 技能定义 | 人工规划、登记在册 | 使用中自己长出来 |
| 权限模型 | ACL（user × skill 对照表）| 图可达性（membership 边）|
| 规模行为 | 平方劣化 | 亚线性摊薄 |
| 技能加载 | 全量注入 | 按需检索 Top-N |
| 技能边界 | 固定 | 随使用演变 |
| 控制目标 | 资源单元（静态快照）| 拓扑关系（动态可达）|
