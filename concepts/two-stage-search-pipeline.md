# 两阶段搜索流水线（Two-Stage Pipeline）

抛弃传统单一检索模式，构建"多路召回 + 排名融合 + 四维业务重排"的工业级搜索引擎架构。

## 总体架构

```
[用户搜索词] ────► 1. 语义向量召回 (HNSW 图检索) ───┐
              └──► 2. 文本精准召回 (倒排索引检索) ─┴─► [3. RRF 排名融合] ──► [4. 四维矩阵业务重排] ──► [输出第一页黄金20席]
```

## 第一步：向量召回路 — AI 语义泛化

**代码实现**：`embedding_dashscope <|300,450|> $qvec`

**底层技术**：[[hnsw-index]]（分层可导航小世界）图索引算法

### 算法逻辑

利用文本向量模型将标题转化为高维稠密向量。HNSW 索引通过类似"跳表"的分层图结构，将空间搜索复杂度从线性 O(N) 暴降至对数级 O(log N)。

### 参数配置：`<|300,450|>`

采用经典的"宽进严出"策略：

| 参数 | 值 | 含义 |
|------|-----|------|
| TopK 返回量 | 300 | 指定向量召回路最终向上层传递的候选节点数量 |
| efSearch 搜索深度 | 450 | 动态控制图检索时的探索边界。深度遍历 450 个潜在节点，防止陷入局部最优的"死胡同"，在牺牲极小计算开销的前提下，换取 95% 以上的近似最近邻（ANN）召回率 |

### 检索贡献

负责"**搜得全**"。实现深层语义泛化，自动拉出高度相似、功能相同的同类替代品，解决字面字符不匹配的漏召回难题。

## 第二步：文本召回路 — 硬核精准匹配

**代码实现**：`goods_name @1@ $keyword ORDER BY ft_score DESC LIMIT 300`

**底层技术**：传统倒排索引全文检索（基于 BM25 词频与逆文档频率算法）

### 检索贡献

负责"**搜得准**"。纯文本匹配作为硬核兜底，对型号、特定品牌词极其敏感，确保标题中包含完全相同数字和关键字的商品被 100% 优先召回，防止大模型向量检索发生语义漂移。

## 第三步：[[rrf-fusion]] 算法融合 — 跨度量衡的排名对齐

**代码实现**：`search::rrf([$vs, $ft], 200, 60)`

### 为什么传统归一化在多路融合中会失效

工程师常犯的错误是使用 Min-Max / Z-Score 对两路分数做传统数学归一化：

**传统做法**：将两路分数分别通过 $S_{new} = \frac{S - S_{min}}{S_{max} - S_{min}}$ 强行拉伸到 [0, 1] 区间，然后再相加。

**致命缺陷**：

| 缺陷 | 说明 |
|------|------|
| **长尾噪音（Outliers）扭曲分母** | 全文检索（BM25）的分数分布极其极端。如果某一极端商品匹配了大量极其罕见的冷门词，它的 S_max 会极其巨大，这会导致其他 99% 的正常商品归一化后的分数全部被压缩在 0.1 左右，失去区分度 |
| **分布不一致（Distribution Mismatch）** | 向量分通常呈现高斯分布或极其稠密的集中分布，而文本分通常呈现长尾（幂律）分布。即使都缩放到 [0, 1]，由于概率密度分布不同，它们依然不具备可加性 |

### 核心作用：消除无量纲特征的壁垒

向量检索分数（VS Score）基于高维空间的余弦相似度，分值在 0.0 ~ 1.0 之间且极其稠密；文本检索分数（FT Score）基于 BM25 算法，是一个没有上限的正数（可能从几到几十）。两者的计量单位和分布区间完全不同，无法直接相加或简单归一化。

**RRF 彻底抛弃绝对分值，仅提取元素在各列表中的相对名次（Rank）进行融合。**

### RRF 的核心目的：构建"非线性、分布无关"的相对位置归一化

RRF 跳出了"对绝对数值进行归一化"的思维陷阱，转而对商品的"相对位置（Rank）"进行归一化。其归一化过程具备三大纯算法优势：

#### ① 统一量纲：将任意数值空间映射到有限的 $(0, \frac{1}{k}]$ 闭区间

无论底层的原始分数是余弦相似度（0.95）、欧氏距离（124.5）还是 BM25 得分（45.8），通过 RRF 变换后，每一路给出的单个商品分值都会被强制归一化到统一的取值范围：

- 当 $k=60$ 时，任何商品的单路 RRF 得分必然落在 $(0, 0.01639]$ 区间内（第一名为 $\frac{1}{60+1} \approx 0.01639$，最后一名无限接近于 0）
- **算法价值**：两路召回的最高分永远对齐为 $0.01639$，彻底抹平了原先的分数壁垒，实现了真正的量纲对齐

#### ② 动态自适应：天然免疫"最大/最小值"的剧烈波动

传统归一化极度依赖当次查询的 S_max 和 S_min。而 RRF 的分母只取决于商品在当前队列中的排名序列（$1, 2, 3...N$）。

- **算法价值**：无论商品库如何扩容、无论用户搜索词多么冷门或热门，RRF 归一化后的分数值和梯度变化永远是恒定且可预测的。这种稳定性对于下游排序网络的泛化至关重要

#### ③ 概率密度平滑：通过倒数实现"非均匀分段缩放"

RRF 的本质是一个高阶非线性归一化函数：

| 区间 | 行为 | 效果 |
|------|------|------|
| **头部区间（Rank 1~10）** | 分值随名次下降而敏锐衰减（从第1名到第10名，分值迅速滑落） | 保持头部的高区分度 |
| **尾部区间（Rank 100+）** | 分值衰减曲线极其平缓，近乎一条直线（第150名和第200名的分差微乎其微） | 自动将长尾低相关性噪音归一化为近乎相同的极低分 |

- **算法价值**：实现了"自动聚焦头部、强行平滑尾部"的归一化效果。算法用最高的敏感度去对比最优秀的候选商品，同时自动将长尾的低相关性噪音商品归一化为近乎相同的极低分，完成了天然的去噪去粗

### RRF 数学公式

$$RRF\_Score(d) = \sum_{m \in M} \frac{1}{k + r_m(d)}$$

| 符号 | 含义 |
|------|------|
| M | 输入的多路召回列表集合（此处为 $vs 和 $ft） |
| r_m(d) | 元素 d 在第 m 路列表中的具体名次（如第 1 名、第 100 名） |
| k | 平滑常数（代码中设定为工业界公认黄金值 60） |

### 五大算法优势

**a. 多路双优元素的激活动能**

由于采用排名倒数相加，如果一个元素在"文本路"和"AI 语义路"里都名列前茅（例如均在前 5 名），其倒数累加和会大幅超越那些"单科状元"（即仅在某一单路拿第一，但在另一路查无此人的单维高分元素），算法层面会自动筛选出综合匹配度最完美的交集项。

**b. 单路算法噪声的天然过滤器**

向量搜索可能因特征泛化导致噪声（误判非相关元素为高分），但在文本倒排中该元素排名无穷大（倒数为 0）。RRF 利用双路机制，自动稀释和惩罚单路异常高分元素，起到极强的算法去噪作用。

**c. 梯度平滑与解耦（k=60 的数学妙用）**

当平滑值 k=60 时，第一名（1/61）和第二名（1/62）的得分差距被大幅缩短至仅有 1.6%。这种非线性变换成功压制了检索头部的马太效应，抹平了绝对分差，将最终的精细化决定权完美解耦并递交给下游的重排级网络。

**d. 统一量纲：任意数值空间映射到 $(0, \frac{1}{k}]$ 闭区间**

无论底层原始分数是余弦相似度（0.95）、欧氏距离（124.5）还是 BM25 得分（45.8），RRF 变换后每一路的单商品分值都被强制归一化到统一取值范围。当 k=60 时，任何商品的单路 RRF 得分必然落在 $(0, 0.01639]$ 区间内，两路最高分永远对齐，彻底抹平分数壁垒。

**e. 概率密度平滑：通过倒数实现"非均匀分段缩放"**

| 区间 | 行为 | 效果 |
|------|------|------|
| 头部（Rank 1~10） | 分值敏锐衰减 | 保持高区分度 |
| 尾部（Rank 100+） | 衰减曲线平缓如直线 | 长尾噪音自动归一化为极低分 |

算法用最高敏感度对比最优秀候选，同时将长尾低相关性噪音天然去噪去粗。

## 第四步：四维矩阵重排 — 业务精细化调优

**代码实现**：`return select ... order by b desc limit 20`

### 数学模型

$$Score(b) = \underbrace{\frac{10.0}{30 + R_{rrf}}}_{\text{相关性（主导）}} + \underbrace{\frac{3.0}{60 + R_{time}}}_{\text{时效性（辅助）}} + \underbrace{\frac{1.0}{60 + R_{sales}}}_{\text{销量（微调）}} + \underbrace{\frac{1.0}{60 + R_{stock}}}_{\text{库存（微调）}}$$

### 权重设计剖析（影响力从高到低）

| 维度 | 权重 | 平滑值 | 设计意图 |
|------|------|--------|---------|
| **相关性** | 10.0 | 30 | 【技术红线控制】分母压缩、分子极大。确保商品必须与算法融合相关性高度挂钩。无论后续业务指标多好，搜索绝对不能跑题 |
| **时效性** | 3.0 | 60 | 【平台生态推新】给予中等权重。在相关性相近时，优先推荐最新更新或上架的商品，激活商城生态，给新商品曝光机会，避免老商品长期霸榜 |
| **销量** | 1.0 | 60 | 【业务转化破局】作为"破局者（Tie-breaker）"。当相关性和时效性持平时，销量高的商品优先排在首屏黄金展位 |
| **库存** | 1.0 | 60 | 【业务转化破局】库存充足的商品优先展示，避免推荐缺货商品 |

### 最终输出

LIMIT 20 → 输出第一页黄金 20 席。
