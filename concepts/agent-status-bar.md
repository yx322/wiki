# Agent 状态列（Agent Status Bar）

在上下文末尾注入结构化元信息，让 LLM 每次生成回复时都能"瞥一眼"当前状态——解决 LLM 被闲聊带跑后忘记待办任务的问题。

## 核心思想

类比手机状态栏：屏幕顶部始终显示时间、电量、信号强度——不是 App 的主界面内容，但你随时可以瞥一眼掌握设备状态。

Agent 状态列对模型起同样的作用：**不是对话主体内容，而是框架在上下文末尾持续注入的状态摘要**。

```
<agent_status>
待办任务：
  [1] 部署生产环境 (skill: deploy)
      ✅ 服务器地址: 10.6.6.88
      ❌ 部署密码: 未收集
当前时间: 2026-08-18 14:30
</agent_status>
```

## 解决什么问题

[[task-memory-ticket]] 解决了**数据层**问题（参数持久化、任务隔离、完成判定），但 `memento_read` 是**被动**的——LLM 要主动调才能看到任务。

**闲聊带跑场景**：

```
用户: "帮我部署生产环境"
LLM: 开始收集参数...
用户: "今天天气真好"          ← 闲聊
LLM: "是啊天气不错..."       ← 被带跑，忘了部署任务
用户: "中午吃什么"           ← 继续闲聊
LLM: "推荐吃火锅"            ← 完全忘了还有任务
```

任务态还在 DB 里，但 LLM 想不起来去调 `memento_read`。

**有了 Agent 状态列**：

```
用户: "今天天气真好"
LLM 看到状态列 → "天气不错！对了，部署生产环境还差一个密码，方便提供一下吗？"
```

## 为什么放在上下文末尾

两个原因：

1. **注意力权重最高**：状态列紧邻模型即将生成的新 token，获得最高注意力权重——"强制性注意力引导"
2. **KV Cache 友好**：追加而非修改 system prompt，前面所有已缓存内容不受影响

```
messages: [
  { role: "system", content: "..." }     ← 固定（KV Cache 缓存）
  { role: "user", ... }                  ← 对话历史
  { role: "assistant", ... }
  ...
  { role: "user", content: "最新消息" }
  { role: "user",                        ← 框架注入的状态列
    content: "<agent_status>...</agent_status>" }
]
```

## 状态列的内容

| 信息类型 | 示例 | 更新频率 |
|----------|------|---------|
| 任务进度 | `[1] 部署生产 ✅服务器地址 ❌密码` | 每轮变化 |
| 工具调用计数 | `phone_call 已调用 3/3 次` | 每轮变化 |
| 当前时间 | `2026-08-18 14:30:45` | 每轮变化 |
| TODO 列表 | `[✓]联络客户 [ ]确认降价` | 每轮变化 |
| 约束检查 | `最大调用次数已达 (3/3) ✗` | 每轮变化 |

## 关键设计原则

### 用代码维护，不用 LLM 维护

状态列必须由框架代码（正则/计数器）维护，不能让 LLM 去读历史、总结状态。

| 维护方式 | 效果 |
|----------|------|
| **代码维护**（20 行正则）| 标准答案级准确度 |
| **LLM 维护**（读完整历史总结）| 大多数格子出错，比不用状态列还差 |

原因：让 LLM 总结长历史 = 把"扫描整段上下文"这个原始难题原封不动搬了个家。

### 写成键值对，不写散文

```
✅ 衣物: 9 件（合格 7、次品 2）     ← 一眼定位
❌ 刚才检查了一批衣物，其中合格的有 7 件...  ← LLM 还得先解析
```

### 状态列的准确率当生产指标盯

模型几乎无条件信任状态列——你写"打了 3 次"，它就当真是 3 次。状态列一旦写错，错误会原样传进最终答案。

## 与任务记忆的配合

三层防线：

```
第一层：任务记忆       = 可靠的持久存储（数据不丢）→ [[task-memory-ticket]]
第二层：Agent 状态列   = 可靠的注意力引导（不会忘）→ 本页
第三层：gate 硬检查    = 可靠的最终防线（没集齐就跑不了）
```

| | 仅任务记忆 | + Agent 状态列 |
|--|-----------|--------------|
| 参数丢失 | ✅ 解决 | ✅ 解决 |
| 多任务隔离 | ✅ 解决 | ✅ 解决 |
| 闲聊带跑 | ❌ LLM 想不起来查 | ✅ 每轮自动看到 |
| 没集齐就跑 | ✅ gate 拦住 | ✅ gate 拦住 |
