# LLM 基础认知

理解 LLM 的正确心智模型：它不是"理解语言的智能体"，而是"匹配统计模式的引擎"。

## 本质：下一字概率预测器

自回归 LLM（GPT、Claude、MiMo 等）的底层机制极其简单：

```
输入：前 N 个 token
输出：第 N+1 个 token 的概率分布
```

它没有"理解"你在说什么，没有"思考"答案是什么，没有内部工作内存。"思考"、"推理"、"理解"——这些都是概率链条在统计意义上的涌现，不是独立的认知过程。

## 无内部状态

LLM 在两次推理之间**没有任何记忆**。每次调用都是从零开始——输入完整的上下文窗口，输出下一个 token。所谓的"记住之前说的话"，只是把之前的对话塞进了上下文窗口。

这就是为什么上下文窗口是 LLM 的工作记忆上限——窗口之外的一切对 LLM 来说不存在。

## 价值公式

```
LLM 的价值 = 视野 × 速度
            ≠ 智力
```

- **视野**：训练数据中见过的模式、架构范式、踩坑经验。中等尺寸模型（7B-70B）已足够覆盖日常工程。
- **速度**：秒级生成代码、方案、分析。人提供判断力，AI 提供速度。
- **智力不是价值**：深度思考模型试图用 LLM 最弱的能力（深度推理）替代最强的能力（广度模式匹配）。

## 三局限

| 层级 | 含义 | 具体失败 |
|------|------|---------|
| **高视野低智力** | 见过大量模式，但缺乏"这个模式在这里不适用"的直觉 | 跨项目知识贯通只覆盖检索层 |
| **平均主义** | 找最可能的路径，但很多任务本质上要求反平均 | 穷举验证、文档生成 |
| **半机械** | 快但不严格，复杂场景不如人类 | 多文件精确对比、深度推理 |

### 三种"聪明"的分布

| 类型 | 分布特征 | 关键时刻 |
|------|---------|---------|
| **人脑的聪明** | 幂率分布 | 少数时刻产生突破性洞察 |
| **机器的聪明** | 确定性 | 规则明确时完美，规则模糊时崩溃 |
| **LLM 的聪明** | 正态分布 | 统计平均，在"大多数情况"下表现很好 |

LLM 没有元认知能力来自适应分配计算资源。所有 token 消耗相同的算力，所有任务获得相同的"注意力"。

## 高维关键词匹配

LLM 看起来远超关键词识别——但事实是：**LLM 从海量语料中学到了"关键词识别"的高维版本**。

```
人类视角：总结 ≈ 汇总（语义相近）
LLM 视角：总结 → [摘要语料分布]，汇总 → [报告语料分布]
          ↑ 两个完全不同的激活路径
```

换一个词比加一段约束更有效——找到那个统计模式恰好等于你想要结果的词。详见 [[llm-prompt-patterns]]。

## 碎片化处理：AI 的比较优势

LLM 碎片化处理能力是结构化处理的 1/10，而人类碎片化处理能力是结构化处理的 1/1000。在碎片化场景中，LLM 保持了 10% 的能力，人类则跌到 0.1%。AI 的相对优势在碎片化场景中反而放大了。
