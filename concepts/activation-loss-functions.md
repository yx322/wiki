# 激活函数与损失函数

激活函数的核心目的是**引入非线性**，决定模型的**表达能力**（能拟合什么）；损失函数衡量**预测值与真实值的差距**，是整个训练的优化目标（往哪拟合）。两者都必须可微（或近似可微），才能参与反向传播。

## 一、激活函数

### 为什么要非线性？

如果不用激活函数（或只用线性函数），无论堆多少层，网络都等价于一层线性变换：

```
y = W2(W1x + b1) + b2 = (W2W1)x + (W2b1 + b2) = Wx + b
```

也就是说，100 层线性层 ≈ 1 层线性层，永远只能拟合直线关系。引入非线性激活后，理论上多层网络可以**逼近任意复杂函数**（万能逼近定理）。

### 常见激活函数对比

| 激活函数 | 公式 | 输出范围 | 特点 | 典型用途 |
|---------|------|---------|------|---------|
| **Sigmoid** | 1/(1+e⁻ˣ) | (0, 1) | 平滑可解释为概率；但梯度消失、非零中心 | 二分类输出层、门控单元 |
| **Tanh** | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | (-1, 1) | 零中心，收敛比 sigmoid 快；仍有梯度消失 | 早期 RNN |
| **ReLU** | max(0, x) | [0, +∞) | 计算极快、缓解梯度消失；但负区间"神经元死亡" | CNN、MLP 隐藏层 |
| **Leaky ReLU** | max(αx, x) | (-∞, +∞) | 负区间保留小斜率，解决死亡问题 | CNN 变体 |
| **GELU** | x·Φ(x) | ≈(-0.17, +∞) | 平滑版 ReLU，带概率色彩 | BERT、GPT 系列 |
| **SwiGLU** | SiLU(xW)⊙(xV) | — | 门控机制 + 平滑激活，效果优于 GELU | **LLaMA、Qwen 等现代 LLM** |

### 演进脉络

```
Sigmoid → Tanh → ReLU → GELU → SwiGLU
（梯度消失问题逐步缓解，计算效率与效果不断提升）
```

Transformer 的 FFN 层早期用 GELU，现在主流开源模型（LLaMA/Qwen/DeepSeek）基本都换成了 **SwiGLU**。

## 二、损失函数

### 目的

损失函数衡量**预测值与真实值的差距**，是整个训练的优化目标。训练过程（梯度下降 + 反向传播）就是不断调整参数让损失变小。

### 常见损失函数

**回归任务**

| 损失 | 公式 | 特点 |
|------|------|------|
| MSE | mean((y-ŷ)²) | 对离群点敏感 |
| MAE | mean(\|y-ŷ\|) | 对离群点鲁棒，但零点不可导 |
| Huber | 结合两者 | 平滑兼顾鲁棒性 |

**分类任务**

| 损失 | 配合的输出激活 | 场景 |
|------|--------------|------|
| BCE（二元交叉熵） | Sigmoid | 二分类、多标签 |
| 交叉熵 CE | Softmax | 多分类 |
| Focal Loss | Sigmoid | 类别极度不均衡 |

### LLM 的损失函数

大模型训练本质上就是**下一个词预测**：

```python
# 伪代码：logits 是对整个词表的打分
logits = model(input_ids)                     # [batch, seq_len, vocab_size]
loss = CrossEntropyLoss(logits, input_ids_shifted)  # 在词表上做交叉熵
```

即把"预测下一个 token"看成 vocab_size 类的分类问题，用交叉熵计算损失。SFT 微调、预训练用的都是这个损失。

## 三、两者的关系

| | 激活函数 | 损失函数 |
|---|---------|---------|
| 作用位置 | 每层网络的内部 | 模型输出之后 |
| 决定什么 | 模型的**表达能力**（能拟合什么） | 优化的**目标方向**（往哪拟合） |
| 是否参与反向传播 | 是（求梯度） | 是（梯度源头） |

几个关键联系：

1. **都要可微**（或近似可微），否则无法反向传播
2. **输出层的激活函数和损失函数通常配套使用**：
   - Sigmoid + BCE
   - Softmax + Cross Entropy
   - 无激活（线性输出）+ MSE（回归）
3. 整个训练闭环：**数据 → 前向计算（激活函数逐层变换）→ 损失函数算差距 → 反向传播梯度 → 更新参数**
