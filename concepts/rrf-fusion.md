# RRF (Reciprocal Rank Fusion)

倒数排名融合算法 — 解决不同搜索路径分数不可比的问题。在 [[surrealdb]] 中通过 `search::rrf()` 实现。

## 为什么传统归一化在多路融合中会失效

工程师常犯的错误是使用 Min-Max / Z-Score 对两路分数做传统数学归一化：

**传统做法**：将两路分数分别通过 $S_{new} = \frac{S - S_{min}}{S_{max} - S_{min}}$ 强行拉伸到 [0, 1] 区间，然后再相加。

**致命缺陷**：

| 缺陷 | 说明 |
|------|------|
| **长尾噪音（Outliers）扭曲分母** | 全文检索（BM25）的分数分布极其极端。如果某一极端商品匹配了大量极其罕见的冷门词，它的 S_max 会极其巨大，导致其他 99% 的正常商品归一化后的分数全部被压缩在 0.1 左右，失去区分度 |
| **分布不一致（Distribution Mismatch）** | 向量分通常呈现高斯分布或极其稠密的集中分布，而文本分通常呈现长尾（幂律）分布。即使都缩放到 [0, 1]，由于概率密度分布不同，它们依然不具备可加性 |

## 核心思想：构建"非线性、分布无关"的相对位置归一化

不看绝对分值，只看排名。RRF 跳出"对绝对数值进行归一化"的思维陷阱，转而对商品的"相对位置（Rank）"进行归一化。将多路搜索结果合并，按每项在各路中的排名计算融合分数。

## RRF 三大纯算法优势

### ① 统一量纲：将任意数值空间映射到有限的 $(0, \frac{1}{k}]$ 闭区间

无论底层原始分数是余弦相似度（0.95）、欧氏距离（124.5）还是 BM25 得分（45.8），RRF 变换后每一路的单商品分值都被强制归一化到统一取值范围：

- 当 $k=60$ 时，任何商品的单路 RRF 得分必然落在 $(0, 0.01639]$ 区间内（第一名为 $\frac{1}{61} \approx 0.01639$，最后一名无限接近于 0）
- **算法价值**：两路召回的最高分永远对齐为 $0.01639$，彻底抹平原先的分数壁垒，实现真正的量纲对齐

### ② 动态自适应：天然免疫"最大/最小值"的剧烈波动

传统归一化极度依赖当次查询的 S_max 和 S_min。而 RRF 的分母只取决于商品在当前队列中的排名序列（$1, 2, 3...N$）。

- **算法价值**：无论商品库如何扩容、无论用户搜索词多么冷门或热门，RRF 归一化后的分数值和梯度变化永远是恒定且可预测的。这种稳定性对于下游排序网络的泛化至关重要

### ③ 概率密度平滑：通过倒数实现"非均匀分段缩放"

RRF 的本质是一个高阶非线性归一化函数：

| 区间 | 行为 | 效果 |
|------|------|------|
| **头部区间（Rank 1~10）** | 分值随名次下降而敏锐衰减（从第1名到第10名迅速滑落） | 保持头部的高区分度 |
| **尾部区间（Rank 100+）** | 分值衰减曲线极其平缓，近乎一条直线（第150名和第200名的分差微乎其微） | 自动将长尾低相关性噪音归一化为近乎相同的极低分 |

- **算法价值**：实现了"自动聚焦头部、强行平滑尾部"的归一化效果。算法用最高敏感度对比最优秀候选商品，同时自动将长尾低相关性噪音天然去噪去粗

## 公式

```
rrf_score = Σ 1 / (k + rank)
```

- `k`：平滑常数，默认 60，防止排名靠后的项贡献过小
- 一个结果在多路搜索中排名都越高，最终得分越高

## SurrealDB 语法

```sql
-- 融合两路搜索，返回 top 5
RETURN search::rrf([$vs, $ft], 5, 60);
```

返回结果只包含文档 ID 和融合分数。

## 适用场景

- 向量搜索（余弦相似度 0~1）与全文搜索（BM25 分数 > 0）分数不可比
- 不需要精细控制权重，排名融合即可满足需求
- 需要简洁的融合方案时

## 与 search::linear 的对比

| 维度 | search::rrf | [[search-linear]] |
|------|-------------|-------------------|
| 输入 | 结果集列表 | [结果集, 分数字段] 列表 |
| 归一化 | 不需要（只看排名） | Min-Max 归一化（有 Outliers 和分布不一致缺陷） |
| 权重控制 | 无（各路等权） | 可指定权重数组 |
| 适用 | 简单融合 | 多路加权融合 |

## 其他算法优势

- **多路双优元素的激活动能**：如果一个元素在两路都名列前茅（如均在前5名），其倒数累加和会大幅超越"单科状元"（仅在某一单路拿第一，另一路查无此人），自动筛选综合匹配度最完美的交集项
- **单路算法噪声的天然过滤器**：向量搜索可能因特征泛化导致噪声，但在文本倒排中该元素排名无穷大（倒数为0）。RRF 自动稀释和惩罚单路异常高分元素
- **梯度平滑与解耦（k=60 的数学妙用）**：第一名（1/61）和第二名（1/62）的得分差距被缩短至仅 1.6%，压制检索头部的马太效应，抹平绝对分差，将精细化决定权递交给下游重排网络
