# LLM 隐藏行为模式与 Prompt 技巧

LLM 对每个中文词都有一套"默认输出模板"。Prompt 工程的本质不是加约束，而是选模板。

## 核心原理

```
加约束 = 试图覆盖默认模板（对抗模型，效果差）
换一个词 = 直接选对模板（顺从模型，效果好）
```

LLM 被训练在海量文本上，每个词都关联着特定文体的输出分布。"总结"的训练数据是摘要（压缩），"汇总"的训练数据是报告（保真）。当你用某个词时，你激活的不是语义，而是**文体模板**。

## 信息密度控制

| 你想要的 | 别说 | 说 | 原理 |
|---------|------|-----|------|
| 保真不压缩 | 总结这段对话 | **汇总**这段对话 | 总结=压缩，汇总=整理保真 |
| 要点不啰嗦 | 写一篇文章 | **列**出来 | 写=散文，列=结构化提取 |
| 精准不展开 | 解释一下 | **说**一下 | 解释=教科书verbose，说=直接结论 |
| 要具体不要抽象 | 学习这个项目 | **抄**这个项目 | 学习=抽象原则，抄=具体代码 |

## 行为方向控制

| 你想要的 | 别说 | 说 | 原理 |
|---------|------|-----|------|
| 精简不膨胀 | 优化这段代码 | **减**这段代码 | 优化=加功能，减=删减 |
| 只填缺口 | 改一下 | **补**一下 | 改=可能重写，补=只补缺失 |
| 要决策不要废话 | 帮我设计系统 | **定**一个方案 | 设计=过度工程，定=做决策 |
| 果断判断 | 讨论这个方案 | **判**这个方案 | 讨论=平衡两边，判=给结论 |

## 交互模式控制

| 你想要的 | 别说 | 说 | 原理 |
|---------|------|-----|------|
| 直接干不废话 | 帮我做一个 X | 做一个 X | "帮我"触发客套确认流程 |
| 严格挑刺 | 评价这段代码 | **批**这段代码 | 评价=温和平衡，批=rigorous |
| 要方案不要清单 | 建议一个方案 | **选**一个方案 | 建议=列选项，选=替你做决策 |

## 为什么约束不如换词

约束是**外力**——你告诉模型"不要做 X"，但默认行为仍然是做 X，只是多了一层检查，会随上下文变长而失效。

换词是**内因**——你改变了输入分布，模型从根源上就不会产出你不要的东西。不需要对抗，没有衰减。

## 通用方法论

当需要加大量约束才能得到想要的结果时：
1. **停下来**：约束太多 = 你在对抗模型的默认行为
2. **找文体**：你想要的输出最像哪种文体？
3. **找触发词**：那种文体的标题/开头通常用什么词？
4. **换词测试**：用那个词替换当前的动词

> 最好的 prompt 是一个词，不是一段话。
